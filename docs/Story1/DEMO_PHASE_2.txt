I. MỤC TIÊU PHASE & SWAGGER API PATH
--------------------------------------------------------------------------------
- Mục tiêu: Kiểm thử quá trình nạp tự động 56 bản ghi từ file Excel Rentzy_AskMe_AI_Training_Data.xlsx vào PostgreSQL 16 và tạo Vector 3072D (gemini-embedding-2) lưu đồng bộ trên Qdrant Cloud, cũng như khả năng nạp tài liệu thủ công qua API Ingest.
- Swagger API Paths:
  1. POST /api/v1/knowledge/seed-excel (Nạp 56 bản ghi tri thức từ Excel)
  2. POST /api/v1/knowledge/ingest (Nạp bài viết mới thủ công)

--------------------------------------------------------------------------------
TESTCASE 2.1: Nạp tự động 56 bản ghi từ file Excel Rentzy (Seed Excel API)
--------------------------------------------------------------------------------
- Swagger API: POST /api/v1/knowledge/seed-excel
- Input: Request HTTP POST (No Body)
- Expected Response (HTTP 200 OK):
  {
    "status": "success",
    "message": "Nạp dữ liệu Excel thành công!",
    "total_ingested": 56
  }
- Giải thích kết quả: Toàn bộ 56 bản ghi kịch bản hỏi đáp chính thức từ file Excel Rentzy đã được đọc, làm sạch, tạo vector embedding 3072 chiều và lưu đồng bộ vào PostgreSQL & Qdrant Cloud với các topic chuẩn như `rentzy_overview`, `deposit_policy`, `rental_pricing`, `deposit_refund`, `showroom_fitting`, `membership`...
