KỊCH BẢN DEMO STORY 1 - PHASE 4: DOCUMENT STATUS MANAGEMENT & GUARDRAILS
================================================================================

I. MỤC TIÊU PHASE & SWAGGER API PATH
--------------------------------------------------------------------------------
- Mục tiêu: Kiểm thử các quy trình kiểm soát trạng thái tài liệu (`active` <-> `inactive`) giúp bật/tắt khả năng tìm kiếm RAG tức thì.
- Swagger API Paths: PUT /api/v1/knowledge/documents/{doc_id}/status (Đổi trạng thái tài liệu)


II. DANH SÁCH TESTCASE DEMO TRÊN SWAGGER
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
TESTCASE 4.1: Chuyển trạng thái tài liệu từ 'active' sang 'inactive' (Tạm ẩn tài liệu)
--------------------------------------------------------------------------------
- Swagger API: PUT /api/v1/knowledge/documents/{doc_id}/status?new_status=inactive
- Input Path & Query: doc_id = "a1b2c3d4-e5f6-7890-abcd-ef1234567890", new_status = "inactive"
- Expected Response (HTTP 200 OK):
  {
    "status": "success",
    "message": "Đã cập nhật trạng thái tài liệu sang 'inactive'",
    "document_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "new_status": "inactive"
  }
- Giải thích kết quả: Trạng thái trong Postgres chuyển sang `inactive`, đồng thời Qdrant Cloud Payload được cập nhật `status = "inactive"` để lập tức ẩn tài liệu khỏi RAG Engine.

--------------------------------------------------------------------------------
TESTCASE 4.2: Khôi phục trạng thái tài liệu từ 'inactive' trở lại 'active' (Kích hoạt lại)
--------------------------------------------------------------------------------
- Swagger API: PUT /api/v1/knowledge/documents/{doc_id}/status?new_status=active
- Input Path & Query: doc_id = "a1b2c3d4-e5f6-7890-abcd-ef1234567890", new_status = "active"
- Expected Response (HTTP 200 OK):
  {
    "status": "success",
    "message": "Đã cập nhật trạng thái tài liệu sang 'active'",
    "document_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "new_status": "active"
  }
- Giải thích kết quả: Tài liệu được kích hoạt lại trên cả PostgreSQL và Qdrant Payload, sẵn sàng cho các truy vấn tìm kiếm RAG tiếp theo.

--------------------------------------------------------------------------------
TESTCASE 4.3: Truyền trạng thái new_status không hợp lệ (Validation Error)
--------------------------------------------------------------------------------
- Swagger API: PUT /api/v1/knowledge/documents/{doc_id}/status?new_status=archived
- Input Query: new_status = "archived"
- Expected Response (HTTP 422 Unprocessable Entity):
  {
    "detail": [
      {
        "loc": ["query", "new_status"],
        "msg": "Input should be 'active' or 'inactive'",
        "type": "enum"
      }
    ]
  }
- Giải thích kết quả: Guardrail mã hóa bảo vệ chặn lập tức các giá trị trạng thái ngoài danh mục cho phép.
